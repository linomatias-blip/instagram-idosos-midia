# Mídias — @linomatias.idosos

Repositório público destinado **exclusivamente à hospedagem de imagens e vídeos** do projeto editorial voltado a profissionais de Educação Física que trabalham com pessoas idosas.

## Atenção
- Arquivos em `rascunhos/` **não estão aprovados para publicação**.
- Hospedar uma imagem neste repositório **não significa** que ela foi cientificamente validada, agendada ou publicada no Instagram.
- Não armazenar credenciais, tokens, dados pessoais ou relatórios internos aqui.
- O código principal e as verificações editoriais permanecem no repositório privado.
